Privacy

Updated November 5, 2026

This static site has no sign-in, submission forms, advertising, analytics scripts or browser storage added by Fear AI.

Hosting and external services

The intended public host is GitHub Pages. Hosting providers may process connection information, including IP addresses and request details. See GitHub’s privacy statement.

Links to Medium, GitHub and other sites take you to services with their own privacy practices. Videos are linked rather than embedded, so they do not load a player here.

Questions

For a general question, use the site repository’s issues. Issues are public; do not include personal or confidential information.
